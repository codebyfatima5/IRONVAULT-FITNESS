# IRONVAULT FITNESS
### Premium Gym & Fitness Management Website

IRONVAULT FITNESS is a modern, responsive gym website designed with a premium Black and Red theme. It provides a complete frontend demonstration of a gym management system with dedicated interfaces for visitors, administrators, members, trainers, and receptionists.

## Project Overview

The project demonstrates how a modern fitness club website and management interface can be designed using HTML, CSS, and JavaScript.

It includes public website pages and role-based dashboard interfaces with interactive frontend features.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layouts
- JavaScript – Frontend functionality and interactions
- LocalStorage – Browser-based demo data storage
- Visual Studio Code – Development environment
- Live Server – Local development and testing

## Installation & Setup

1. Download or clone this repository.
2. Extract the project folder if downloaded as a ZIP.
3. Open the folder in Visual Studio Code.
4. Install the Live Server extension if it is not already installed.
5. Open `index.html`.
6. Right-click and select **Open with Live Server**.

The website will open in your browser.

## Demo Login Credentials

This is a frontend demonstration, not a production authentication system.

- Email: Enter any valid-format email address.
- Password: Enter any non-empty password.
- Role: Select the required demo role, if the login page provides role selection.

No real account or password is required. Access depends on the demo login implementation.

## Important Project Notes

- This project is frontend-only.
- No PHP or MySQL backend is included.
- Demo data and interactions use browser LocalStorage where implemented.
- Authentication is not secure or production-ready.
- Payments are demonstrations only; no real transactions are processed.
- User data is stored locally in the browser and is not shared across devices.
- Internet access may be required for externally hosted images and Google Fonts.

## Project Purpose

The purpose of this project is to demonstrate frontend web development skills, responsive UI design, JavaScript interactions, dashboard layouts, and the structure of a gym management application.
